# 앱인토스 마이페이지 + 매칭 상세(연락처·채팅) 설계

날짜: 2026-07-10 · 범위: 앱인토스 미니앱 SPA(`apps-in-toss/`) · 결제 없음(심의 초판)

## 문제

미니앱에 주문/입찰 화면만 있고, **기사는 자기 입찰·매칭·받을 금액을 볼 화면이 전혀 없음**. 결제를 뺐기 때문에 매칭 후 화주↔기사가 실제로 연결될 수단(연락처·대화)도 없음 → 매칭이 반쪽.

## 결정

- 전화번호 출처 = `users.phone`. 마이페이지/매칭상세에서 입력·수정(로그인 자동저장은 기존유저·optional 이슈로 불채택).
- 연락 방식 = **A(연락처 노출) + B(앱내 채팅) 병행**.
- 채팅 = 기존 `chats` 테이블 재사용. 신규 마이그레이션 없음.

## 확인된 스키마/RLS (전부 기존)

- `matches(id, order_id, driver_id, status['accepted'|'in_progress'|'completed'|'cancelled'], matched_at)`, UNIQUE(order_id,driver_id)
- `bids(id, order_id, driver_id, price, message, status['pending'|'accepted'|'rejected'])`
- `orders.status`: pending→matched→…
- `chats(id, match_id, sender_id, message, sent_at)` — RLS select/insert = 매칭 당사자(driver_id=uid OR order.shipper_id=uid)
- `users_select` RLS = `USING(true)` → SPA에서 상대 `name`,`phone` 직접 조회 가능
- `users_update` = 본인행만 → phone 자기수정 OK

## 컴포넌트

### `MatchDetail.tsx(orderId)` — 양쪽 공용, 핵심
- match 해소: `matches.eq(order_id).single()` → driver_id. order에서 shipper_id. 뷰어가 기사면 상대=화주, 아니면 기사.
- 헤더: 출발→도착 / 확정금액(수락된 bid.price) / 상태
- 상대 카드: 이름 + `tel:` 전화 링크
- 내 연락처 미등록 시: 안내 + 입력 → `users.update({phone}).eq(id,me)`
- 채팅: `chats.select().eq(match_id).order(sent_at)` + 4초 폴링, 하단 입력→insert(sender_id=me). (realtime publication 의존 회피 위해 폴링)

### `DriverMy.tsx` — 기사 마이페이지(신규)
- `bids.select("id,price,status,order_id, orders(origin,destination,pickup_at,status)").eq(driver_id,me)`
- 요약칩: 매칭 n건 · 예상수익 합(accepted bid.price 합)
- 리스트: 출발→도착 / 내 입찰가 / 상태(대기·수락됨·마감) / 픽업. accepted → `onOpenMatch(order_id)`

### `MyOrders.tsx` — 화주(수정)
- 상단 요약칩(진행중/완료 건수·총 확정액) 추가. 기존 onOpen→OrderDetail 유지.

### `OrderDetail.tsx` — 화주(수정)
- order.status==='matched'면 "상대 연락처·채팅" 버튼 → `onOpenMatch(order_id)`

### `App.tsx` — 배선
- view: `driver-my`, `match-detail` 추가. 기사 홈에 "내 입찰·매칭" 버튼.
- `onOpenMatch(orderId)` → detailId=orderId, view=match-detail.

## 심의 영향

- 연락처는 매칭 당사자 UI에만 노출 + 약관 "매칭 시 연락처 상호제공"·개인정보 3자제공 항목 이미 반영.
- 앱내 채팅 → 미니앱 완결성 강화(플러스).

## 범위 밖(후속)

탁송 완료처리·리뷰·정산·결제. 초판 = 매칭 + 연락처 + 채팅까지.

# BUG-011 미결제 상태 완료확인 시 "이미 처리된 완료 요청" 오표시

| 항목 | 값 |
|---|---|
| 심각도 | Minor |
| 우선순위 | P4 |
| 상태 | Open |
| 관련 TC | TC-029 |
| 관련 POL | POL-040 |
| 발견 위치 | `app/actions/orders.ts:146-148` (confirmCompletion) |

## 기대 결과
- escrow가 아직 없는(미결제) 매칭에서 완료확인 시, "결제가 완료되지 않았습니다" 같은 정확한 안내.

## 실제 결과
- escrow 미존재와 이미 released/refunded를 동일하게 `!escrow || escrow.status !== "held"` 한 조건으로 묶어 **"이미 처리된 완료 요청입니다"** 반환. 미결제 상태를 "이미 처리됨"으로 오안내.

## 원인 분석 (확정)
- escrow null(미결제)과 status 불일치(기처리)를 구분하지 않음.

## 조치 (제안)
```ts
if (!escrow) return { error: "아직 결제가 완료되지 않았습니다" }
if (escrow.status !== "held") return { error: "이미 처리된 완료 요청입니다" }
```
- 재검증: TC-029 재실행 + TC-021 회귀.

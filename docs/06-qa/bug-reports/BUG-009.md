# BUG-009 KYC 재제출 제한/쿨다운 부재 (POL-052 미구현)

| 항목 | 값 |
|---|---|
| 심각도 | Minor |
| 우선순위 | P4 |
| 상태 | Fixed |
| 관련 TC | TC-047 |
| 관련 POL | POL-052(KYC 재제출) |
| 발견 위치 | `app/api/kyc/verify/route.ts` (제출 진입부 — 재시도 카운트 없음) |

## 기대 결과
- POL-052: 거절 후 재제출 횟수 제한·쿨다운으로 반복 위·변조 제출 방지.

## 실제 결과
- 거절(rejected) 이후 즉시 무제한 재제출 가능. 매 호출마다 스토리지 업로드 + Claude Vision 실행 → 비용 발생, 남용 벡터.

## 원인 분석 (확정)
- kyc_submissions 이력은 쌓이나, 제출 진입부에서 최근 시도 횟수/시각 기반 차단 로직 없음.

## 조치 (제안)
- 제출 진입부에서 최근 kyc_submissions 조회 → 일정 시간 내 N회 초과 시 429/쿨다운 안내. 임계값은 POL-052 확정과 함께.
- P4: 즉시 위험은 낮으나 비용·남용 관점에서 론칭 초기 모니터링 필요.

## 조치 결과 (Fixed)
- `kyc/verify/route.ts` 진입부에 24h 재제출 한도(RESUBMIT_LIMIT=3) → 429. 추가로 누적 시도 2회+ 시 confidence≥0.72라도 자동승인 차단→manual_review 강제(임계값 gaming 방지). tsc 통과.

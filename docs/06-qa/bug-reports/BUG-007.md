# BUG-007 매칭·결제 후 취소/환불 경로 부재 (POL-043 미구현)

| 항목 | 값 |
|---|---|
| 심각도 | Minor |
| 우선순위 | P3 |
| 상태 | Open |
| 관련 TC | TC-028 |
| 관련 POL | POL-043(취소·환불) |
| 발견 위치 | `app/actions/orders.ts:178-197`(cancelOrder) |

## 기대 결과
- POL-043: 탁송 시작 전 취소 시 전액 환불, 기사 귀책 취소 시 화주 전액 환불. 매칭·결제(held) 이후 시작 전 단계에도 취소·환불 경로가 있어야 함.

## 실제 결과
- `cancelOrder`는 `status === "pending"`만 취소 허용. 매칭(matched)·결제(in_progress) 이후에는 취소 불가. 결제금(held) 환불은 오직 **분쟁(dispute)** 경로로만 처리 가능 → 단순 상호 합의 취소나 기사 미이행 상황에 대응하는 정상 취소·환불 플로우 없음.

## 원인 분석 (확정)
- 취소 상태 화이트리스트가 pending 단일. 환불(refunded) 전이 트리거가 분쟁에만 존재.

## 조치 (제안)
- 시작 전(matched/held, match.status != in_progress) 취소 액션 신설: escrow refunded 전이 + Toss 취소 API 호출 + 알림. 화주/기사 귀책 구분과 위약금(POL-043 ④⑥, 🔴 위약금율 표 확정 선행) 반영.
- 우선순위 P3: 초기 론칭은 분쟁 경로로 커버 가능하나, 정책 문구와 실제 동작 불일치는 CS 리스크.

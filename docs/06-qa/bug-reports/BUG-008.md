# BUG-008 KYC 파일 업로드 타입/용량 검증 부재 (POL-022 미구현)

| 항목 | 값 |
|---|---|
| 심각도 | Minor |
| 우선순위 | P3 |
| 상태 | Open |
| 관련 TC | TC-046 |
| 관련 POL | POL-022(파일 업로드 제한) |
| 발견 위치 | `app/api/kyc/verify/route.ts:338-402` |

## 기대 결과
- POL-022: 허용 확장자(이미지/PDF)·최대 용량·서버측 MIME 검증.

## 실제 결과
- 파일 존재만 확인. 확장자는 파일명에서 추출(기본 'jpg')하고, MIME/용량 검증 없이 스토리지 업로드 + Claude Vision 전송. 대용량·비이미지 파일이 그대로 처리되어 비용·오류·스토리지 오염 유발 가능.

## 원인 분석 (확정)
- 업로드 검증 로직 부재.

## 조치 (제안)
- 업로드 전 `file.type` 화이트리스트(image/jpeg,png,webp,application/pdf) + `file.size` 상한(예: 10MB) 검증, 위반 시 400.
- 재검증: TC-046 재실행 + TC-040 정상 제출 회귀.
